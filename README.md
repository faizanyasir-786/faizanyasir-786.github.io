# Muhammad Faizan Yasir | Portfolio

Personal portfolio website, live at https://faizanyasir-786.github.io

Built for CS-117 Applications of ICT, Assignment 2.

## About
A one-page portfolio with my bio, skills, projects and contact links, hosted on GitHub Pages.

## Built with
Based on the [Simplefolio](https://github.com/cobiwave/simplefolio) template by Jacobo Martínez (MIT licence, see `LICENSE.md`). Built with Parcel, Bootstrap and Sass, and deployed with GitHub Actions.

## Run locally
Requires Node 16.14.2.

    npm install
    npm start

Then open http://localhost:1234.
